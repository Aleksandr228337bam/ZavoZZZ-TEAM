# ZavoZZZ-TEAM

            Название
Расписание ИТ Москва

            Описание проекта
Данный проект представляет собой веб-сервис для просмотра расписания занятий колледжа. Сервис позволяет студентам выбрать свою учебную группу и сразу получить актуальное расписание занятий в удобном виде. Основной интерфейс сервиса реализован в виде Telegram-бота, а веб-версия используется в качестве демонстрационной и учебной реализации в соответствии с требованиями задания.

            Принцип работы
1. Пользователь открывает веб-страницу сервиса.
2. Переходит в раздел «Расписание».
3. Выбирает свою учебную группу из предложенного списка.
4. Расписание выбранной группы автоматически отображается на странице.
Все данные о расписании хранятся в JavaScript в виде стактурированных объектов.

            Запуск проекта
Для запуска проекта необходимо:
1. Скачать файл index.html.
2. Открыть его в любом современном веб-браузере (Google Chrome, Microsoft Edge, Firefox и др.).
Дополнительная установка программного обес чения не требуется

            Функциональные ВОЗМОЖНОСТИ
1. Выбор учебной группы из списка;
2. Отображение расписания занятий для выбранной группы;
3. Динамическое обновление данных без перезагрузки страницы;
4. Интерактивная таблица с расисанием занятий;
5. Простой и понятный пользовательский интерфейс.
